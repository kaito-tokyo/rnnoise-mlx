# Licensing and model provenance

Project source is distributed under BSD-3-Clause. Files adapted from RNNoise
retain their original copyright and BSD notice.

Release model provenance must list every audio dataset, its license, the data
preparation revision, training configuration, random seed, and evaluation
results. Upstream/Xiph model weights and their outputs may be used only as a
separately reported validation baseline. They must not initialize, supervise,
distill, select pseudo-labels for, or otherwise influence released weights.
